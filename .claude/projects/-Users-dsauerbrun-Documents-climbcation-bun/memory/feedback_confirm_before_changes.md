description: User must explicitly approve before any code changes are made

Always present findings and a proposed plan, then wait for the user to say "yes" or explicitly ask to proceed before making any code edits.

**Why:** User was frustrated when changes were made immediately after research without being asked first.

**How to apply:** After any research/investigation, summarize findings and proposed changes, then stop and wait for confirmation. Do not make changes proactively even if the fix is obvious.
